# Security policy (draft)

Star OS is in Phase 0. There are no releases, and nothing here is meant for
production use.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting for this repository ("Security" tab → "Report a
vulnerability"). The repository owner must enable this feature.

## Supported versions

None yet. A support policy will be published before the first public stable
release, as required by the project specification (§29).

## Prototype builds

ISO files produced by CI are **unsigned test artifacts**. They are not
official builds and must not be redistributed as such.
